# Αυτοψία αντλίας θερμότητας

Εφαρμογή ιστού για iPhone: φόρμα αυτοψίας με επιλογές, Ναι/Όχι, 12 θερμαντικά σώματα με απόδοση 75/60 °C,
άνοιγμα του αρχείου εξαγωγής του Dynamics και επιστροφή του συμπληρωμένου Excel.

Άνοιγμα: https://nikosxir.github.io/autopsia/ → Safari → Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας».

Οι αυτοψίες αποθηκεύονται μόνο στη συσκευή (localStorage). Δεν ανεβαίνουν δεδομένα σε αυτό το αποθετήριο.
Οι αποδόσεις σωμάτων είναι ενδεικτικές τιμές καταλόγου (EN 442, 75/65/20), μετατρεπόμενες στις συνθήκες λειτουργίας.
